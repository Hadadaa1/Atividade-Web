# 🚀 Projeto Blog Pessoal - Parceria com IA

Este repositório contém um blog pessoal simples desenvolvido como parte de uma atividade prática. A página foi estruturada utilizando tecnologias web fundamentais e contou com o auxílio de inteligência artificial para a geração do código e design.

## 🛠️ Tecnologias Utilizadas
* **HTML5**: Estruturação semântica da página.
* **CSS3**: Estilização, layout responsivo em Grid/Flexbox e transições visuais.

## 🤖 IA Utilizada no Desenvolvimento
* **Gemini 3.5 Flash (Google)**: Atuou como copiloto no desenvolvimento, estruturando o código HTML, criando a folha de estilos CSS responsiva e redigindo os textos e a documentação deste repositório.
